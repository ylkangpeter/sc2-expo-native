# SC2 Expo Native (星际争霸2 合作任务原生轻量辅助悬浮窗)

> [!NOTE]
> 本项目是 Python/PyQt 原版 [**sc2-expo**](https://github.com/ylkangpeter/sc2-expo) 的全新 **C++20 + DirectX 11 + Dear ImGui** 原生重构版本。
> • 原版 Python 仓库地址：[https://github.com/ylkangpeter/sc2-expo](https://github.com/ylkangpeter/sc2-expo)
> • 本原生版本仓库地址：[https://github.com/ylkangpeter/sc2-expo-native](https://github.com/ylkangpeter/sc2-expo-native)

参考了优秀轻量化 Windows 原生工具（如 `SC2聊天过滤器v5.0`）的技术架构，实现了极致的小体积、高性能与零外部依赖运行，同时 **100% 保持原有业务逻辑与非侵入式原则**。

## 核心特性与对比

| :--- | :--- | :--- | :--- |

| **图形渲染** | Qt5 Widgets 软件/硬件混合绘制 | **DirectX 11 硬件加速** + DWM 桌面合成 | **无撕裂、真透明** |

| **托盘与管理** | 依赖外部托盘脚本 | **系统任务栏原生托盘图标 (单击切换显示/隐藏，右键设置与管理菜单)** | **随时调整尺寸与Toast、锁定、退出** |

## 功能完整性保障 (与原版完全对齐)

1. **严格非侵入式 (Strictly Non-Intrusive)**:
   - 绝不修改 `SC2_x64.exe` 进程内存，绝不注入任何 DLL，绝不修改游戏数据。
   - 仅通过星际争霸 2 官方客户端本地内置开放 HTTP API (`http://localhost:6119/game` 和 `/ui`) 获取对局时间与状态。
2. **合作任务 17 张全地图自动识别**:
   - 完整移植 17 张合作任务地图的玩家数量与多语言 AI/中立生物名称匹配模式。
   - 支持简体中文、繁体中文、英文、韩文、俄文、德文、法文、波兰文、西班牙文、意大利文等所有游戏语言。
   - 自动检测新对局（玩家阵容变动或对局时钟重置），自动识别地图并加载时间轴。
3. **时间轴与红点波次动态显示**:
   - 实时读取并同步 `resources/maps/` 对应地图的波次时间表。
   - 过去事件灰度显示，当前/即将到来事件绿色高亮，并在表格中自动居中滚动。
   - 支持地图分支版本一键切换（如 `往日神庙-A / B`、`虚空撕裂-左 / 右`），提供界面切换按钮与全局热键。
4. **红点与关键目标全屏悬浮 Toast 提醒**:
   - 在红点或目标波次到达前 30 秒，屏幕底部中央自动弹出醒目的半透明 Toast 警告框。
   - 采用独立 Win32 分层原生窗体（`SC2ToastOverlayNative`），具备 100% 穿透特性。
   - 支持在设置中自由调整垂直屏幕高度比例（`toast_position_y`）、尺寸缩放比例（`toast_scale`）与显示持续时长。
   - 显示事件倒计时、波次描述、科技等级（T1~T7）以及敌方兵种组成图标与混合体数量。
5. **每周突变因子倒计时提醒与贴边极简布局**:
   - 包含 5 种高威胁突变因子：虚空演化 (`deployment`)、传播者 (`propagator`)、虚空裂隙 (`voidrifts`)、杀戮机器人 (`killbots`)、自爆机器人 (`bombbots`)。
   - 悬浮窗上提供一键启用/禁用图标，窗体底边紧贴 5 个突变图标，彻底杜绝多余空白留白。
6. **泽拉图全神器点位透视悬浮 (严格地图匹配)**:
   - 仅对存在泽拉图神器的 6 张地图（`死亡摇篮`、`湮灭快车`、`净网行动`、`营救矿工`、`亡者之夜`、`熔火危机`）开放神器展示。
   - 当对局为无神器地图时，严格杜绝误弹图，神器按钮自动禁用并显示 `当前地图无专属神器`。
   - 按下快捷键 `Ctrl + Shift + \` 或 `Ctrl + \` 展开当前地图的高清泽拉图神器分布图。
   - 原版 6 张 13 MB 的 PNG 图片已优化为无损级 WebP，体积降至 1 MB 左右，通过 Windows WIC 硬件加速解码。
7. **指挥官快速替换器 (Commander Selector)**:
   - 支持国服 (`CN`)、韩服 (`KR`)、欧服 (`EU`)、美服 (`US`) 四大区域。
   - 18 位合作任务指挥官全头像网格排布 + 随机替换按钮。
   - 双击任意头像即可一键复制官方街机替换链接（如 `替换为raynor指挥官: battlenet:://starcraft/map/3/148741`）到 Windows 剪贴板，并弹出提示。
   - 支持排除黑名单中的指挥官进行随机替换。
8. **全局热键与免输入法冲突设计**:
   - `Ctrl + Shift + ]` 或 `Ctrl + ]`: 切换点击穿透锁定 / 解锁状态。
   - `Ctrl + Shift + [` 或 `Ctrl + [`: 切换当前地图的 A/B 或 左/右 分支版本。
   - `Ctrl + Shift + \` 或 `Ctrl + \`: 切换泽拉图神器点位透视图。
   - `Ctrl + Shift + -`: 调试与状态信息查看。
   - 增加了无需 Shift 的直接组合键（如 `Ctrl + [`），避免触发 Windows 默认的输入法语言切换快捷键。
9. **独立居中设置窗口 (设置 & Toast 字体/边框调色)**:
   - 托盘右键菜单提供 `设置` 选项。
   - 采用完全独立的 Win32 原生窗体（`SC2SettingsWindowNative`），默认居中显示于屏幕，可按住任意空白处或标题自由拖拽，**绝不与主悬浮窗粘连**。
   - 窗体尺寸大幅扩展至 **380 × 600**，布局宽裕舒适，所有滑动条、调色器、提示说明与按钮完整展示，不出现任何截断。
   - 支持滑动条实时动态调整主窗宽度 (默认 173，范围 140~320px)、主窗高度 (默认 340，范围 180~500px)、表格高度 (默认 228，范围 90~320px)，调节即时联动主窗。
   - 支持文字字体缩放滑块（`font_scale` 0.75x ~ 1.50x）。
   - 支持 Toast 垂直显示位置（默认 0.18）、Toast 整体尺寸缩放（默认 1.43x）、显示持续秒数调节。
   - **Toast 颜色深度自定义**：新增 **Toast 文字颜色** (`toast_text_color`) 与 **Toast 边框颜色** (`toast_border_color`) 实时调色盘选择，支持点击色块开启完整调色板调节。
   - 提供 `[ 测试 Toast 效果 ]` 按钮，一键在屏幕上直观预览当前设置下的 Toast 颜色、缩放与垂直位置效果。
   - 提供 `[ 保存设置 ]` 持久化到 `config.json` 与 `[ 恢复默认 ]` 一键复原全部标准默认值。
   - 移除了所有在非 Emoji 字体下会渲染成问号 `?` 的字符，界面文字干净规范。

## 使用与操作说明

1. **启动与界面**:
   - 直接双击运行 `dist/sc2_expo/sc2_expo.exe`。
   - 默认以 **173 × 340 实用尺寸工具窗口**（表格高度 228）呈现在屏幕上，去除了顶部冗余的标题拖拽标签和关闭按钮，更加通透极简。
   - **启动默认处于点击穿透锁定状态**，完全不干扰星际争霸 2 或桌面的任何操作。
   - 边框采用沉稳低调的深色半透明样式，杜绝刺眼的红绿色边框。
2. **常驻锁头与锁定/解锁操作**:
   - 悬浮窗正上方常驻一个精致的 **28 × 28 独立控制锁头 (`SC2LockWindowNative`)**。
   - **核心优势**：即使主窗口处于 100% 穿透状态（`WS_EX_TRANSPARENT`），该锁头窗口依然永远接收鼠标点击！
   - 点击锁头即可随时在 **锁定 (🔒 穿透状态)** 与 **解锁 (🔓 可交互状态)** 之间无缝切换；鼠标悬停有高亮与手型光标提示。
   - 亦可随时按下全局热键 `Ctrl + Shift + ]` 或 `Ctrl + ]`，或在系统托盘右键菜单中切换锁定。
   - 解锁状态下，直接按住主窗口背景或首行 `Time:` 即可拖拽移动，锁头自动吸附同步跟随，位置自动持久化到 `config.json`。
3. **系统任务栏托盘 (单击隐藏/显示 & 专属设置)**:
   - 程序在 Windows 任务栏通知区域常驻专属托盘图标。
   - **单击托盘左键**：一键切换主窗口与锁头的隐藏 / 显示状态。
   - **右键托盘图标**：弹出快捷菜单，支持锁定/解锁、分支版本切换、泽拉图神器、展开指挥官替换器、**设置** 与安全退出。
4. **独立设置面板 (Settings Window)**:
   - 从托盘菜单打开设置后，弹出独立的 **380 × 600 居中设置窗体**，可按住任意空白处或标题栏自由拖拽，完全不与主悬浮窗粘连。
   - 可直接拖动滑动条调整：主窗宽度 (默认 173，范围 140~320px)、主窗高度 (默认 340，范围 180~500px)、表格高度 (默认 228，范围 90~320px)、文字字体大小 (0.75x~1.50x)。
   - 可配置 Toast 垂直高度比例（默认 0.18）、Toast 整体尺寸缩放（默认 1.43x）、提示持续秒数。
   - **支持 Toast 字体与边框颜色自定义**：提供 `Toast文字颜色` 与 `Toast边框颜色` 调色板，并支持 `[ 测试 Toast 效果 ]` 随时查看实时效果。
   - 支持一键 `[ 保存设置 ]` 与 `[ 恢复默认 ]`。
5. **指挥官替换抽屉**:
   - 在解锁状态下，点击悬浮窗底部的 `[ 替换指挥官 ]`，窗口将向右平滑展开 920 宽度的指挥官网格面板。
   - 单击任意指挥官头像即可一键复制对应的街机替换指令到剪贴板，并提示成功；点击 `[ 随机指挥官 (Random) ]` 可排除黑名单随机抽取。
   - 点击右上角 `[ 收起 X ]` 或再次点击按钮，窗口自动收回为紧凑尺寸。
6. **泽拉图神器点位透视 (严格对应地图)**:
   - 在游戏内任意时刻按下全局热键 `Ctrl + Shift + \` 或 `Ctrl + \`，若当前地图属于 6 张神器图之一，屏幕中央立即展示当前地图的高清泽拉图神器分布透视图及指示标。
   - 若当前地图无神器，将自动保持隐藏并给出相应提示，绝不乱弹图。再次按下快捷键快速关闭。

## 编译与测试指南

### 环境要求
- 编译工具链: LLVM-MinGW (Clang++ 17+)
- 运行环境: Windows 10 / 11 64-bit

### 编译与打包
在本项目目录下执行：
```bash
python build.py
```
打包脚本将：
1. 编译生成原生 Windows 64 位高效可执行文件 `sc2_expo.exe` (约 2.14 MB)。
2. 自动同步所需配置与资源至便携目录 `dist/sc2_expo/`。
3. 自动打包生成便携绿色分发包 `dist/sc2_expo_native.zip`。
> 注：`dist/` 目录已配置在 `.gitignore` 中，不纳入版本控制。

### 运行自动化验证测试
```bash
python build.py test
./test_runner.exe
python tests/verify_app.py
python tests/test_lock_toggle.py
python tests/test_artifact_toggle.py
python tests/test_commander_toggle.py
```
全套自动化测试套件涵盖：
- 117 项核心业务逻辑测试（配置读写、地图多语言多玩家识别、时间轴、兵种等级匹配、突变因子时钟、指挥官替换与链接、WIC WebP 解码、Toast 色彩与缩放参数验证）。
- 窗体非全屏、非抢占式鼠标交互、全局热键实时切换、神器点位穿透显示、抽屉平滑伸缩等 Windows 原生行为全自动验证。
